# Project Resume Workflow

Last updated: 2026-03-02 01:14 UTC

## Purpose
Define repeatable resume behavior for ongoing milestone execution without re-initialization.

## Required Read Order
1. Read root `roadmap.md` to identify current milestone and gate requirements.
2. Read `docs/README.md` to identify milestone-relevant detailed docs.
3. Read only the docs needed for the active milestone.
4. Read latest entries in `projects/frontiertrace-agentic-benchmark.md` and task report.

## Resume Checklist
- Confirm active milestone and open gates.
- Confirm pending artifacts required for gate validation.
- Confirm unresolved blockers from prior milestones.
- Confirm remote policy status before starting deliverables that need collaboration/review.

## Execution Rule
- No repository scaffold regeneration.
- No duplicate init docs.
- Execute only milestone-scoped work and record gate evidence.
