# Open-Web Runtime Policy (Draft v0)

Last updated: 2026-03-02 00:33 UTC

## Principle
Internet access remains enabled because extensive search is a core capability under test.

## Allowed behavior
- Agents may search beyond provided paper graph.
- Agents may use external tools to discover relevant literature.

## Disallowed behavior
- Direct hidden-solver leak usage.
- Verbatim copying from discovered solver content without demonstrated understanding.

## Enforcement
- Hidden-solver leak controls in task packaging.
- Plagiarism similarity checks on final proof text.
- Post-solution understanding checks (derivation/explanation probes) to reject copy-only outputs.
