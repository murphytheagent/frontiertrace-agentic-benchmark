# Project Init and Resume Workflow

Last updated: 2026-03-02 00:33 UTC

## Purpose
Define the reusable mini-workflow for starting or resuming work on this project with minimal context loss.

## Required Read Order
1. Read root `roadmap.md` for current milestone, gate metrics, and blocking criteria.
2. Read `docs/README.md` to identify required detailed docs.
3. Read only milestone-relevant docs in `docs/` (schema, lineage, audit, runtime, references).
4. Review latest task report and project report entries before implementation.

## Execution Rule
- No implementation begins until the current milestone gates and required docs are read.
- If roadmap and docs disagree, roadmap controls sequencing, docs control detail.

## Resume Checklist
- Confirm active milestone and open gates.
- Confirm pending artifacts required for gate validation.
- Confirm no blocked dependency from prior milestone.
- Record planned actions against current milestone only.
